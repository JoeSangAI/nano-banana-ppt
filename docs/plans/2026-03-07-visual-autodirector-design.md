# Nano Banana PPT Visual Auto-Director Design

## 概述

本设计的目标，是把 `nano-banana-ppt` 的图片能力从“图片插入器”升级为“自动视觉导演”。

核心原则只有两条：

1. 人工介入尽量只发生在 `plan_for_review.md` 阶段，用于确认叙事、文本、页数与页面目标。
2. `execute` 阶段尽量全自动完成选图、模式选择（`overlay` / `blend`）、摆位、融合和亮点处理，不额外打断用户。

这意味着系统需要把“图片相关决策”拆成多个更稳定的自动步骤，而不是让一个模型一次性决定一切。

---

## 设计目标

### 1. 尽量少人工干预
- 用户在 `plan` 阶段确认“讲什么”。
- 用户不需要逐页确认“用哪张图”或“图放哪里”。
- 低置信度时系统自动降级，而不是频繁回头问用户。

### 2. 自动做出更像设计师的判断
- 自动判断某页需要“证据图”还是“氛围图”。
- 自动判断更适合 `overlay` 还是 `blend`。
- 自动从多个布局模板中挑选最合理的一种，而不是完全自由摆放。

### 3. 在不稳定时优先保守
- 选图不确定时，不强行出错图。
- 融合不确定时，优先退回可控的 `overlay`。
- 摆位不确定时，优先使用模板安全区，而非任由 VLM 漂移。

---

## 核心问题拆解

### 问题一：如何找到“最适合的图片”

不能把“找图”和“决定是否使用”混在一起。

正确做法是拆成三层：

1. **候选图召回**
   - 从源文档抽出的本地图片
   - 文档里引用的网络图片
   - 后续可扩展的人物肖像、品牌图、概念图外部来源

2. **候选图过滤**
   - 过滤二维码、广告图、纯装饰图、模糊图、无关截图
   - 输出每张图的语义描述、可读性判断、信息密度判断

3. **页面级选图排序**
   - 对每一页单独比较候选图与该页 `core_message` / `narrative_role` / `visual_suggestion`
   - 输出：
     - `best_image`
     - `score`
     - `reason`
     - `recommended_mode`

这样模型不是“凭感觉挑一张”，而是在候选集上做排序决策。

### 问题二：如何决定 `overlay` 还是 `blend`

系统不应默认只有一种模式，而应自动分类：

- **`overlay`**
  - 适用于截图、图表、报表、新闻图片、界面图、复杂结构图
  - 目标：保真、清晰、不可被重绘

- **`blend`**
  - 适用于人物肖像、产品氛围图、背景物件、抽象概念图
  - 目标：让素材“长进”背景里，与整页风格一致

模型在执行阶段为每页每张候选图自动输出 `recommended_mode`，随后由规则层再二次校验：

- 含大量文字/数据/表格的图，强制回退为 `overlay`
- 人像、无高密度文本的照片，优先允许 `blend`

### 问题三：如何让图片放在正确的位置

不能直接让 VLM 自由决定位置，否则在混合模式里容易漂移。

更稳的方式是：

1. 先根据页面类型选择 **布局模板**
   - 左文右图
   - 右文左图
   - 半屏人像融合
   - 全屏背景弱融合
   - 上图下文
   - 居中主视觉 + 边角数据

2. 再在模板的合法区域内，让 VLM 做 **局部微调**
   - 不能跨越模板定义的左右侧语义边界
   - 只能在安全区里移动和缩放

3. 对混合模式增加 **区域锁定**
   - `blend` 占据的主视觉区域不能再被 `overlay` 重用
   - `overlay` 必须保留在其指定半区或指定象限

## 自动视觉导演的执行链

### 阶段 A：页面视觉意图判断

输入：
- 页面文本
- `core_message`
- `narrative_role`
- `visual_suggestion`

输出：
- 本页是否需要图片
- 图片用途：证据 / 氛围 / 人物 / 数据 / 对比
- 推荐布局模板

### 阶段 B：候选图理解与打分

对每张候选图输出：
- `semantic_summary`
- `image_type`
- `text_density`
- `person_present`
- `relevance_score`
- `suitability_for_overlay`
- `suitability_for_blend`

### 阶段 C：页面级选图决策

对每一页，从候选图中选出：
- 0 张或 1 张主图
- 可选 1 张辅助图

同时输出：
- 为什么选它
- 为什么不用其他候选图
- 使用 `overlay` 还是 `blend`

### 阶段 D：布局与安全区决策

在模板内决定：
- 左 / 右 / 中
- 占比
- 裁切策略
- 文本避让区

### 阶段 E：生成后的视觉复核

再让一个轻量视觉检查步骤验证：
- 图有没有压字
- `overlay` 是否跑到错误区域
- `blend` 是否过重或喧宾夺主
- 是否和页面语义冲突

如果复核失败，自动进入降级逻辑。

---

## 降级策略

为了减少人工打断，系统在低置信度时自动回退：

### 选图低置信度
- 默认不强行上图
- 退回纯视觉背景页，或者采用抽象隐喻

### 模式低置信度
- 默认回退到 `overlay`
- 尤其是包含文字、图表、数字密集内容时

### 布局低置信度
- 不允许 VLM 自由漂移
- 回退到模板预设安全区

### 混合模式冲突
- 如果 `blend` 与 `overlay` 抢同一区域，则保留 `overlay` 正确性，缩弱或取消 `blend`

## 对现有系统的改造点

### `NarrativeAgent`
- 不再只输出“有无 `native_images`”
- 增加页面视觉目标描述字段，便于执行阶段独立选图
- 可保留初始建议，但不要求它在 `plan` 阶段就完全决定最终图片

### `review_plan`
- 用户仍然只确认叙事和页面方向
- 可显示“本页建议视觉类型”，但不要求用户逐图微调

### `executor`
- 新增自动视觉导演流程：
  - 候选图加载
  - 候选图打分
  - 页面级选图
  - `overlay/blend` 模式选择
  - 模板内摆位

### `generator`
- `blend` 继续走参考图融合
- `overlay` 继续走留白 + 后贴图
- 混合模式时增加区域锁定，不让二者互相覆盖

## 成功标准

### 用户体验
- 用户只在 `plan` 阶段确认内容，不在执行时频繁被追问
- 同一份内容多次执行，视觉决策总体稳定

### 工程指标
- `blend` 单独模式稳定成功
- `overlay` 单独模式稳定成功
- 混合模式下，`overlay` 不跨区漂移
- 低置信度时自动降级而非输出明显错误结果

### 视觉指标
- 选图明显更贴题
- 人像融合更自然
- 截图与图表依然清晰可读
- 页面更像“设计好的幻灯片”，而不是“图被塞进去的幻灯片”

---

## 推荐实施顺序

1. 先解决 **混合模式布局稳定性**
2. 再做 **候选图打分与自动选图**
3. 最后做 **生成后视觉复核与自动降级**

原因是：
- 先稳住布局，能立刻减少明显错误
- 再提升选图准确率，收益最大
- 最后补上复核与回退，系统才真正适合长期自动运行
