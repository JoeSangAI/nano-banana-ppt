# Nano Banana PPT Visual Tuning & Dual-Director Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Refactor the `plan` phase into a two-stage "Dual-Director" workflow (Content Plan -> Visual Manifesto -> Prototype) to eliminate cheap AI visuals and improve template integration.

**Architecture:** 
1. Split `plan` command into generating `content_plan.md` (Copywriter) and `plan_for_review.md` (Art Director).
2. Introduce a new `Art Director` prompt chain to generate a `design_system_manifesto` that bans cliché AI elements and forces adherence to templates.
3. Introduce a `prototype` command to render 1-2 slides quickly for style confirmation.
4. Modify `generator.py` and `review_plan.py` to inject the `design_system_manifesto` into every `visual_prompt`.

**Tech Stack:** Python, OpenAI API (Gemini), python-pptx
